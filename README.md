# Облік-Склад

Україномовна система обліку речового майна.

## Принцип
Фактичні складські дані та реальні залишки не входять до проєкту. Користувач заповнює їх самостійно.

## Основні модулі
- Склади та місця зберігання
- Матеріально відповідальні особи
- Номенклатура та NSN
- Прихід
- Видача
- Переміщення
- Списання
- Автоматичні залишки
- Картка обліку
- Журнал руху

## Статус
Фундамент проєкту створюється. APK буде сформовано після завершення функціоналу та успішної CI-перевірки.
