# Облік-Склад

Україномовна офлайн-система обліку речового майна для Android.

## Принцип

Фактичні складські дані, реальні залишки та службові записи не входять до репозиторію. Користувач заповнює їх самостійно на пристрої.

## Основні модулі

- Склади та МВО
- Комірки / місця зберігання
- Номенклатура, NSN, одиниця виміру, партія та ціна
- Надходження
- Видача
- Переміщення між складами та комірками
- Списання
- Автоматичний контроль залишків
- Контроль залишків на рівні комірки
- Картки обліку
- Журнал руху з документом, маршрутом, комірками та приміткою
- Редагування та безпечне видалення довідників
- Локальна SQLite база без обов'язкового інтернету

## Надійність

- SQLite foreign keys увімкнені.
- Переміщення записуються атомарною транзакцією.
- Документи не дозволяють списати більше доступного залишку.
- Якщо обрана комірка, контролюється залишок саме цієї комірки.
- Пов'язані склади, матеріали та комірки не можна випадково видалити.
- Дата документа перевіряється строго у форматі YYYY-MM-DD.
- Некоректні числові значення та помилки SQLite обробляються без аварійного завершення.
